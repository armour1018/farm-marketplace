# Harvest Haven Marketplace

A modern marketplace app for selling healthy farm animals and fresh farm produce.

## Features
- Premium landing page for a farm marketplace
- Product catalog for animals and produce
- Product detail pages
- Shopping cart with quantity controls
- Responsive layout built with Next.js and Tailwind CSS

## Tech stack
- Next.js 14
- TypeScript
- Tailwind CSS
- React Context for cart management

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Project structure
- `app/` – pages and app router layout
- `components/` – reusable UI elements
- `lib/` – product data and shared logic
